03 / INTEGRATION

External Agent API & SDK

Connect any AI agent to GoalFault's sandbox via HTTP or protect production code with @guard.

OPEN BENCHMARK
Sandbox Tool EndpointREST API

Point your agent's tool execution calls to this endpoint instead of live production backends:

POST /api/scenarios/GF-001/sandbox/call Content-Type: application/json { "tool": "issue_refund", "arguments": {"order_id": "ORD-180", "amount": 180}, "enforce": false }

GoalFault returns whether the call was allowed, real-time policy violations, and state diffs:

{ "allowed": true, "violation": {"policy": "P-101", "invariant": "no_unauthorized_refund"}, "state_delta": {"orders.ORD-180": {"refunded": 180.0}}, "proof_url": "/runs/RUN-XXXXX" }
